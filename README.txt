票据识别与校对台 · Windows x64 便携版

1. 先将 ZIP 完整解压到一个普通文件夹。
2. 打开 ReceiptReviewDesk 文件夹，双击 ReceiptReviewDesk.exe。
3. 请保留同目录的 _internal 文件夹。不要只复制 EXE，也不要在压缩包预览窗口里直接启动。

无需安装 Python，无需 OCR 账号。支持图片与 PDF 识别、原文定位、校对、导出已确认票据为 Excel，以及删除或清空票据记录。

票据默认保存在 %LOCALAPPDATA%\ReceiptReviewDesk。发布包不包含打包电脑上的票据、校对记录或工作区数据库。OCR 在本机运行。

此版本未做 Authenticode 签名。请只从可信的 Release 下载，并核对发布者提供的 SHA-256。

第三方许可和库的源码见 third-party-notices。应用源码、构建脚本及测试样张见 source。
